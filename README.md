# 👋 Hi, I'm Ilham Radan
SOC Analyst | Blue Team | Cybersecurity
## 👨‍💻 About Me

I’m a Computer Science graduate from Pakuan University with hands-on IT Support and infrastructure experience across government and healthcare environments. My background includes network infrastructure, system administration, hardware and software troubleshooting, and maintaining reliable IT operations.

I’m currently transitioning into cybersecurity, with a strong focus on Blue Team and Security Operations. Through structured training and hands-on labs, I’m developing practical experience in security monitoring, log & event analysis, SIEM, IDS, network traffic analysis, and digital forensics across Windows and Linux environments.

I’m particularly interested in SOC Analyst, Security Monitoring, and Blue Team roles, where I can combine my IT infrastructure foundation with growing capabilities in threat detection, investigation, and incident response.

### 🛡️ Security Focus

- 🔵 **Blue Team & SOC** — Security monitoring, alert triage, log analysis, and incident investigation.
- 📊 **Security Monitoring** — SIEM, Windows/Linux event analysis, and security log investigation.
- 🌐 **Network Security** — IDS/IPS, network traffic analysis, and packet/PCAP investigation.
- 🔎 **Digital Forensics** — Evidence analysis and investigation across Windows and Linux environments.
